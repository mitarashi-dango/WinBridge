# GitHubの検索向け公開設定

READMEの公開とあわせて、リポジトリのAbout欄に以下を設定します。このファイルを配置するだけではGitHubの説明やTopicsは変更されません。

## Description

```text
Build your own Windows 11 control panel: choose settings shortcuts, reorder items, hide unused modules, and organize favorites. 自分好みのコントロールパネルを作れる無料アプリ。C# / WPF.
```

## Topics

```text
windows-11, windows-settings, control-panel, customization, desktop-app, productivity, settings-manager, windows-utility, wpf, csharp, dotnet
```

既存のTopicsがある場合は内容を確認して追加・整理します。機能に関係しない人気キーワードは追加しません。

## 公開後の確認

- README.mdとREADME.en.mdをGitHubに反映し、言語切り替えと最新版ダウンロードのリンクを確認します。
- About欄のDescriptionとTopicsを設定します。
- GitHubで `WinBridge in:name,description,readme` や `topic:windows-settings` を検索して表示を確認します。
- Googleで `site:github.com/mitarashi-dango/WinBridge` を検索して登録状況を確認します。反映時期や検索順位は保証されません。

GitHubのREADMEではページのHTMLタイトルやmeta descriptionを直接制御できないため、用途が伝わる見出し・冒頭の説明・関連リンクを整えています。
